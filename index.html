Formal 5-Tuple Definition

Formally, the password complexity validator is modeled as a Deterministic Finite Automaton (DFA):

M = (Q, Σ, δ, q0, F)

• Q = QC × QL (16 complexity states × 9 length states = 144 product states)
• Σ = ΣU ∪ ΣL ∪ ΣD ∪ ΣS
• q0 = (q0000, L0) (Initial start state)
• F = {(q1111, L8+)} (Singleton accepting set)

Deterministic Property: For every state $q \in Q$ and input symbol $a \in \Sigma$, there is exactly one designated transition $\delta(q, a) \in Q$, ensuring zero backtracking and strictly linear $O(n)$ time complexity.

Regular Language Closure Proof

Why is password validation guaranteed to be a Type-3 Regular Language?

Lvalid = LU ∩ LL ∩ LD ∩ LS ∩ L≥8

Where:
• LU = Σ* ΣU Σ* (contains uppercase)
• LL = Σ* ΣL Σ* (contains lowercase)
• LD = Σ* ΣD Σ* (contains digit)
• LS = Σ* ΣS Σ* (contains special)
• L≥8 = Σ8 Σ* (length at least 8)

Closure Theorem: The class of regular languages is closed under intersection. Because all five constituent sub-languages are regular, their intersection $L_{\text{valid}}$ is strictly regular.

NLP Tokenizers & Lexical Analysis

In Natural Language Processing (NLP) pipelines and compiler front-ends, raw text must first be split into tokens (words, punctuation, numbers).

Text Stream → [ Lexical Analyzer (DFA) ] → Token Stream

Examples in NLP:
• Word Tokenizers (splitting contractions: "don't" → "do", "n't")
• Entity Extractors (Dates, Currency, Passwords, Emails)
• Byte-Pair Encoding (BPE) & WordPiece subword vocabularies

Tools like Lex and Flex take Regular Expressions, compile them into Non-deterministic Finite Automata (NFAs) via Thompson's Construction, and then into minimized DFAs via the Powerset Construction.

DFA vs. Regex Engine Backtracking

Standard regular expressions for password validation use Lookahead Assertions:

^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[!@#$%^&*]).{8,}$

Comparison Matrix:

  • Regex Engine (PCRE): May cause ReDoS (Regular Expression Denial of Service) through catastrophic backtracking ($O(2^n)$ in worst-case).
  • Automata DFA: Scans the string in a single linear pass ($O(n)$ time), storing state in a tiny 4-bit register ($O(1)$ memory).
